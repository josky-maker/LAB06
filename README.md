# LAB06 실험 전 보고서

UART 통신 과제 5·6·7과 FPGA 서보모터·SRAM·DAC 실습 준비 자료입니다.

- 01~11 PNG: 제공된 Word 문서에서 그대로 추출한 사진 원본. 보고서 그림 번호와 일치합니다.
- LAB06_사진과소스.zip: 폴더 구조를 유지한 원본 사진, 보고서용 발췌본, RTL, TB, XDC, 기존 로그·VCD, STM32 과제별 소스, SHA-256 목록.
- PDF: 8쪽 사전보고서. 표지, 2단 본문, 핵심 코드, 파형 해석, 검증 결과와 실험 계획, 참고문헌.

기존 FPGA 로그는 PASS이며 새로 재실행한 결과는 아닙니다. STM32 사진은 빌드 종료 코드 0의 증거로, 실제 통신 성공과 구분합니다. 실제 보드 계측은 수업에서 수행할 항목입니다.

최종 제출 버전은 prelab-v1.0.0 태그로 확인합니다. 보고서의 소스 기준 커밋은 사진 및 소스 묶음을 고정한 선행 커밋입니다.
